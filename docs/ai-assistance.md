# AI Assistance

Codex assisted with implementation, tests, documentation, and review. The public repository contains only curated project artifacts; it does not include chat transcripts, hidden instructions, private reasoning, model-provider exports, or session logs.

The reviewed observation fixture is cryptographically bound to the real pre-cook input image. The public image is authentic, deterministically cropped, and metadata-free. The baseline does not claim that a model created the reviewed observations.
